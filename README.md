# 🎮 Geometry Dash Level Recommender Mod

![C++](https://img.shields.io/badge/C++-17-blue?logo=cplusplus)
![CMake](https://img.shields.io/badge/CMake-Build-green?logo=cmake)
![Geode Framework](https://img.shields.io/badge/Geode-Framework-purple)

Mod desarrollado en C++ utilizando el framework **Geode** para Geometry Dash. Recomienda dinámicamente 20 niveles destacados de la comunidad directamente dentro del juego.

## 🛠️ Tecnologías Utilizadas

- **Lenguaje**: C++17
- **Construcción**: CMake
- **Framework Target**: Geode SDK
